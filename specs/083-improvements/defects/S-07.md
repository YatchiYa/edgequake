# S-07 — No access-token revocation; iss/aud unchecked

> **Priority**: P1  
> **Audit status**: FIXED

---

## 1. WHY

Stolen access token valid ~24h; logout only kills refresh.

---

## 2. Audit (code is law)

| Field | Value |
|-------|-------|
| Primary locus | `edgequake-auth/src/jwt.rs:75-91,162-168` |
| Verdict | **FIXED** |

---

## 3. Root cause (first principles)

jti minted but never stored; iss/aud None; validation skips them.

---

## 4. ASCII causal diagram

```

  logout --> revoke refresh only
  access(jti) --> still valid until exp
```

---

## 5. Solution (SOLID + DRY)

Require iss/aud; jti denylist (or denylist+TTL store) on logout; short access TTL.

| Principle | Application |
|-----------|-------------|
| S | Own the invariant in one module named in the solution |
| D | Depend on SSOT helpers (SchemaReadiness, TenantContext, RetryExecutor, TokenEstimator, …) |
| DRY | No second copy of normalize / retry / GUC / score scale |

---

## 6. Edge cases

clock skew leeway; multi-instance denylist needs Redis/PG

## 7. E2E / contract tests

e2e_logout_rejects_access_jti; contract_jwt_requires_iss_aud
