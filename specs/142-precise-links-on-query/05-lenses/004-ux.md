# Lens 004 — UX

## Stake

Users must **see** and **verify** evidence without hunting. Citations are trust
anchors, not decoration.

## Experience principles

1. Inline link text = human name + page (`Q3.pdf, p.4`).
2. Click = same workspace document viewer, correct page + chunk highlight.
3. While streaming, show catalog chips early; replace with verified markdown at Done.
4. Unknown / stripped cites leave no broken footnote.
5. Non-PDF: name link without page param — no fake `p.1`.
6. Refusal / empty RAG: no empty citation chrome.

## Acceptance probe

Ask a question whose answer is only on PDF page 4 → click link → page indicator
shows 4, not 1.
