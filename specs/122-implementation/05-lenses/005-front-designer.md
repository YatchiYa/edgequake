# Lens 005 — Front Designer

## Stake

Bulk progress chrome must stay calm: one composition, status as text+motion, no sticker-badge clutter.

## Visual rules

```ascii
  ┌─ Documents ─────────────────────────────────────────┐
  │  Dropzone (transfer only)                           │
  │  ═══════════════════════════════════  file 2/5      │
  │                                                     │
  │  Banner (optional, one line):                       │
  │  Processing 1 of 5 — local LLM runs one at a time   │
  │                                                     │
  │  Rows: title · status · relative time               │
  └─────────────────────────────────────────────────────┘
```

1. No hero cards for queue metrics.
2. Motion: subtle row status transition; transfer bar only during admit.
3. Color not sole status channel.
4. Preserve existing design system tokens.
