# CNC Manufacturing Glossary

**CNC**: Computer Numerical Control - automated machine tools controlled by computer programs
**G-code**: The programming language used to instruct CNC machines
**Spindle speed**: The rotational speed of the cutting tool in RPM
**Feed rate**: The speed at which the workpiece advances relative to the cutting tool
