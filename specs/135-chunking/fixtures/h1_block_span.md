# Synthetic H1 block

Short remainder on page one. Unique token EQ135_H1_P1. This page is undersize so a
naive packer would want to steal page two. It must not, because page two starts a new
H1.

# Completely different topic

Page two is a new document section. Unique token EQ135_H1_P2. Cross-page packing is
blocked when the next unit is a new ATX H1 (edge E1).
