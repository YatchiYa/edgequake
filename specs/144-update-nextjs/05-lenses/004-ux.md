# Lens — UX

## User-visible goals

1. **No regression:** Documents, query streaming, graph, login redirects feel
   the same after the bump.
2. **Faster cold nav (Phase C):** Home ↔ Documents shows a shell immediately
   when Instant Navigations is enabled for that allowlist.
3. **Honest loading:** Prefer existing skeletons / `loading.tsx` over blank
   flashes when shells are adopted.

## Interaction contracts

| Surface | Expectation |
|---------|-------------|
| Login redirect | Deep link returns after auth cookie present |
| Query answer | Tokens stream; no “wait then dump” |
| Document sync | SPEC-143 wheel / sync toggle unchanged |
| API explorer | Swagger assets load (trailing slash) |
| List nav (Phase C) | Shell visible before full data when allowlisted |

## Anti-UX

- Enabling Instant Navigations globally so PDF detail flashes empty shells.
- Changing visual design system as part of this upgrade.
- Silent failures when auth middleware is “accidentally” bypassed.
