# Lens — UX

## User goals

1. Natural continuous reading of PDF with wheel / trackpad.
2. Instant understanding that Markdown follows the PDF page (and vice versa).
3. Escape hatch when sync fights intentional comparison.

## Interaction model

```ascii
  Sync ON (default, side-by-side)
    PDF scroll/page  ──► Markdown jumps to page section
    Markdown scroll  ──► PDF scrolls to matching sheet

  Sync OFF
    Independent scroll (today's behavior)
```

## Feedback

| Signal | Form |
|--------|------|
| Active PDF page | Toolbar `N / Total` + `data-page` |
| Active MD page | Soft sticky “Page N” label (minimal, non-card) |
| Sync state | Toggle with tooltip: “Synchronize PDF and Markdown pages” |
| No markers | Toggle disabled; tooltip explains |

## Accessibility

- Keyboard PageUp/Down / Arrows when PDF pane focused.
- Sync toggle focusable; `aria-pressed`.
- Page anchors `aria-hidden` (decorative); live page announced via toolbar.

## Anti-patterns

- Cards / badges clutter in hero of the pane.
- Auto-forcing sync after user turns it off mid-session.
- Jumping both panes on every 1px scroll (use IO + settle).
