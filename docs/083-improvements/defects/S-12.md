# S-12 — Filename unsanitized; MIME from extension only

> **Priority**: P1  
> **Audit status**: FIXED  
> **Cluster**: [`02-auth-transport`](../clusters/02-auth-transport/)  
> **Sprint**: 1

---

## 1. WHY

Path tricks in stored names; content/MIME mismatch; no AV.

---

## 2. Audit (code is law)

| Field | Value |
|-------|-------|
| Primary locus | `file_upload.rs:63-67; file_validation.rs:111-151; pdf magic only` |
| Verdict | **FIXED** |
| Verified against | HEAD audit 2026-07-23 (v0.20.2 lineage) |

---

## 3. Root cause (first principles)

Multipart filename trusted; get_mime_type(extension) only.

---

## 4. ASCII causal diagram

```

  upload "../../x.pdf" --> stored as-is
  "x.exe" renamed .pdf --> MIME application/pdf (WRONG)
```

---

## 5. Solution (SOLID + DRY)

sanitize_filename (strip path, control chars); magic-byte sniff for allowed types; reject mismatch. AV = ops optional hook.

| Principle | Application |
|-----------|-------------|
| S | Own the invariant in one module named in the solution |
| D | Depend on SSOT helpers (SchemaReadiness, TenantContext, RetryExecutor, TokenEstimator, …) |
| DRY | No second copy of normalize / retry / GUC / score scale |

---

## 6. Edge cases

unicode names; double extension

---

## 7. E2E / contract tests

contract_filename_strips_path; e2e_exe_as_pdf_rejected
